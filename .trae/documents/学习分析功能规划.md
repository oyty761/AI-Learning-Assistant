# 学习分析功能规划（简化版）

## 一、项目现状分析

### 1.1 技术栈
- **前端**: Vue.js 3 + Element Plus + Vite
- **后端**: Java Spring Boot 3.x + H2数据库
- **AI服务**: 百度文心一言 API / 华东师大ChatECNU

### 1.2 现有数据实体
- `ErrorRecord` - 错题诊断记录
- `UserErrorProfile` - 用户错误档案
- `Note` - 笔记数据
- `QaHistory` - AI问答历史
- `Todo` - 待办事项

## 三、功能模块（简化版）

### 模块一：学习数据看板 (Dashboard)

**功能描述**: 展示核心学习指标概览

**包含指标**:
- 📊 **总诊断次数** - 累计错题诊断数量
- 📈 **本周活跃度** - 近7天学习活动统计
- 🎯 **薄弱知识点数** - 需要重点关注的知识点数量
- ✅ **任务完成率** - 待办事项完成情况
- 📚 **笔记数量** - 整理的学习笔记总数
- 💬 **问答次数** - 与AI导师互动次数

**UI形式**: 6个卡片式指标展示

---

### 模块二：学习活跃度日历

**功能描述**: 展示每日学习活动情况

**展示形式**:
- 类似GitHub贡献图的日历热力图
- 颜色深浅表示当日学习活动次数
- 悬停显示具体活动详情

**数据来源**: ErrorRecord + Note + QaHistory 的 createdAt

---

### 模块三：智能学习报告 (Smart Report)

**功能描述**: AI生成的个性化学习分析报告

**报告内容**:
1. **学习概况总结**
   - 总体评价（积极/需改进）
   - 学习强度评估

2. **薄弱点分析**
   - 高频错误知识点Top5
   - 错误类型倾向分析
   - 改进建议

3. **进步亮点**
   - 已掌握的知识点
   - 错误减少的趋势

4. **学习建议**
   - 针对性练习推荐
   - 学习计划调整建议

**生成方式**: 基于统计数据 + AI文本生成

## 四、技术实现方案（简化版）

### 4.1 后端实现

#### 新增API接口

```java
@RestController
@RequestMapping("/api/analysis")
public class LearningAnalysisController {
    
    // 获取学习数据看板
    @GetMapping("/dashboard")
    public ResponseEntity<DashboardVO> getDashboard(@RequestParam String userId);
    
    // 获取学习活跃度日历数据
    @GetMapping("/activity-calendar")
    public ResponseEntity<List<ActivityVO>> getActivityCalendar(@RequestParam String userId);
    
    // 生成智能学习报告
    @GetMapping("/report")
    public ResponseEntity<ReportVO> generateReport(@RequestParam String userId);
}
```
